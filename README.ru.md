# PlayStation 5 Local

[English](README.md) · **Русский**

Наблюдение и управление PlayStation 5 из Home Assistant по локальной сети. Для каждой консоли создаётся своё устройство с постоянными идентификаторами сущностей. Интеграция использует Remote Play напрямую и работает без MQTT и отдельного приложения.

| Сущность | Что делает |
| --- | --- |
| Состояние питания | Показывает, включена ли PS5 или находится в режиме покоя с доступом к сети. Если консоль перестаёт отвечать, сущность становится недоступной. |
| Игра или приложение | Показывает название, которое сообщает PS5. Если консоль его не передала, значение неизвестно. |
| Идентификатор игры | Дополнительный диагностический датчик. Показывает точный идентификатор, если PS5 его передала. |
| Питание | Будит сопряжённую консоль или переводит её в режим покоя. Home Assistant ждёт, пока PS5 подтвердит переход. |
| Главный экран | Дополнительная кнопка для включённой сопряжённой консоли. Включите её в списке сущностей устройства. Remote Play не сообщает, сменился ли экран. |

## Установка

В Home Assistant 2026.11 и новее добавьте репозиторий GitHub как пользовательскую интеграцию через **Настройки → Marketplace**. Для Home Assistant 2026.10.4 используйте **HACS → Пользовательские репозитории** и выберите тип «Интеграция». Для ручной установки распакуйте ZIP из релиза в `custom_components/ps5_local/` и перезапустите Home Assistant.

Минимальная поддерживаемая версия Home Assistant указана в [hacs.json](hacs.json).

## Настройка консоли

1. На PS5 откройте **Настройки → Система → Дистанционное воспроизведение** и включите его. Для пробуждения по сети откройте **Настройки → Система → Энергосбережение → Функции, доступные в режиме покоя**. Включите **Сохранить подключение к интернету** и **Разрешить включение PS5 через сеть**.
2. В Home Assistant откройте **Настройки → Устройства и службы → Добавить интеграцию → PlayStation 5 Local**. Найдите консоль в сети или введите её IPv4-адрес. Чтобы адрес оставался постоянным, закрепите его в настройках DHCP роутера. Если адрес изменится, выберите **Перенастроить** в интеграции.
3. Выберите **Только наблюдение**, чтобы начать без входа в PlayStation. Для питания и кнопки «Главный экран» выберите **Сопряжение для управления питанием**. Сопряжение доступно и позже через настройки интеграции. На включённой PS5 откройте **Привязать устройство** и введите восьмизначный PIN в Home Assistant. Укажите ID аккаунта Remote Play или адрес страницы, на которую вас перенаправит Sony после входа по ссылке из формы. Если профиль консоли защищён четырёхзначным кодом входа, задайте его в настройках интеграции.

Опрос и управление идут по локальной сети. При входе по ссылке из формы Home Assistant обращается к Sony, чтобы получить ID аккаунта. Данные сопряжения и код входа в профиль, если он задан, хранятся в конфигурации Home Assistant. Храните резервные копии Home Assistant в закрытом доступе.

Если у вас уже есть другая интеграция PS5, сначала включите наблюдение параллельно. Проверьте пробуждение и режим покоя, затем переведите автоматизации на новые сущности. Удаляйте старую интеграцию после проверки автоматизаций.

## Язык интерфейса

Окна настройки используют язык вашего профиля Home Assistant. Интеграция поддерживает русский язык и использует английский для остальных языков. Названия сущностей по умолчанию определяются системным языком Home Assistant. Имена, заданные вручную, сохраняются.

## Если что-то не работает

- Если поиск по сети ничего не нашёл, введите IPv4-адрес вручную. Home Assistant должен иметь доступ к локальному Remote Play на PS5. Полностью выключенная консоль может быть недоступна.
- Если PS5 отклоняет переход в режим покоя или команду «Главный экран», проверьте, активен ли другой сеанс Remote Play и нужен ли код входа в профиль консоли.
- Некоторые версии прошивки и состояния консоли не передают сведения об игре. Датчик питания может работать и без этих данных.
- Диагностика содержит доступность, состояние питания, версию прошивки и признак сопряжения. Данные сопряжения, IP и активность в неё не входят.

## Разработка и выпуск

Запустите `python -m pytest -q` с Home Assistant Core 2026.11.1 и зависимостями из `requirements-test.txt`. Соберите архив командой `python tools/build_release.py --tag v0.1.0` и приложите `dist/ps5_local.zip` к соответствующему релизу GitHub. Для подачи в общий каталог нужен опубликованный релиз и успешные проверки HACS и hassfest. [Руководство по каталогу Marketplace](https://contributors.home-assistant.io/marketplace/guides/catalog/)

Для сопряжения и управления питанием используется [ps5-remoteplay](https://github.com/iharosi/ps5-remoteplay), основанная на playactor и Chiaki. Кнопка «Главный экран» использует команду, описанную в [исходниках playdirector 0.3.0](https://pypi.org/project/playdirector/0.3.0/).

Проект распространяется по лицензии AGPL-3.0-only и не связан с Sony Interactive Entertainment.
